# Roadmap MGIMO-LMS

Обновлено: 15 ноября 2026. Дополнения команды по итогам МФТИ.
Все пункты ниже запланированы; этот список не подтверждает их реализацию.

**Внутренний срок — доделать до 19 ноября 2026**, оставив время на доработку
документации и выступления. Подробности и критерии приёмки —
в [плане подготовки к финалу](docs/final-preparation.md).

- [ ] Рассчитать юнит-экономику продукта. Ответственный — **Legpopov**, [задача #34](https://github.com/Ekanam-Friends/MGIMO-LMS/issues/34).
- [ ] Соединить RAG с API генерации YandexGPT или GigaChat и выбрать провайдера по проверкам.
- [ ] Проверить соответствие ответов положениям, включая случай «отпуск → командировки».
- [ ] Подготовить финальную презентацию в стиле МГИМО.
- [ ] Исправить выбор действующей редакции на указанную дату и проверять свежесть корпуса.
- [ ] Оценить несколько агентов с микрозадачами и сборкой ответа: качество, задержку и стоимость в сравнении с простым RAG.
- [ ] Добавить проверку обоснованности и законности действий в отношении студента по локальным нормативным актам вуза и актам Минобрнауки: обстоятельства, применимые нормы и редакции, основания вывода, недостающие сведения. [Подробные критерии](docs/final-preparation.md#7-проверка-действий-в-отношении-студента).

подтверждаться проверками, а не только описанием.
