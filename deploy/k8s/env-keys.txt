# Как переменные из .env попадают в кластер (решение 0028). Читают scripts/k8s-up.sh

#
# ЗАКРЫТО ПО УМОЛЧАНИЮ: ключ, которого здесь нет, k8s-up.sh кладёт в Secret и предупреждает.
# В ConfigMap (открытым текстом) попадают только ключи config и envonly.
#
#   secret  KEY — секрет: только в Secret lms-secrets, никогда в ConfigMap и в репозитории.
#   config  KEY — несекретная настройка: из .env -> ConfigMap lms-env (перекрывает base/config.env).
#   envonly KEY — несекретная настройка без безопасного значения по умолчанию в base/config.env;
#                 берётся только из .env (ConfigMap lms-env).
#   managed KEY — задаёт кластер/скрипт; значение из .env игнорируется.
# Новую несекретную переменную добавляйте сюда как config, иначе она уйдёт в Secret.
