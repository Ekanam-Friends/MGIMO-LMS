# MGIMO-LMS — инструкции для ИИ-агентов

Прототип личного кабинета студента МГИМО для хакатона MGIMO×AI Challenge (вайб-кодинг).
Бриф, требования и критерии — в [README.md](README.md). Принятые решения —
в [docs/decisions/](docs/decisions/), начни с `0001-architecture.md`.

## Стек 

FastAPI + PostgreSQL + Jinja2 + HTMX. Telegram-бот на aiogram. LLM — GigaChat или YandexGPT,
вызовы только с бэкенда. Деплой — docker-compose на VPS за общим Caddy.

## Жёсткие правила задания

- **Только вымышленные данные.** Ни одного реального ФИО студента или преподавателя, зачётки, оценки.
  При импорте расписания ФИО преподавателей заменяются на сгенерированные.
- **Студент видит только своё.** Любой запрос к данным студента фильтруется по id из сессии.
  Чужой id в адресе → 404. Проверка на уровне запроса к БД, не в шаблоне.
- **Секреты не в коде.** Ключи LLM, токен бота, пароль БД — только в `.env`, который в `.gitignore`.
  В репозитории — `.env.example` без значений. Ничего из этого не попадает в HTML или JS.
- **Пароли только хэшем** (argon2 или bcrypt).
- **Мобильный экран от 360 px** — каждый новый экран проверяется на этой ширине.
- **Не официальный сервис.** На каждой странице видна плашка «концепт для конкурса». Логотип вуза
  не используется.

## Правило документирования — обязательная часть каждой задачи

Критерий «Масштаб нейротехнологий» (10 из 40 баллов) оценивается по документу о процессе.
Поэтому **задача не считается сделанной**, пока не выполнено всё ниже:

1. В `docs/prompts/<область>.md` добавлена запись: дата, кто ставил задачу, ключевой промпт
   (или краткий пересказ диалога), что получилось с первого раза, что пришлось переделать.
2. Если ИИ ошибся (неверный код, выдуманная библиотека, нарушение правила выше) — запись
   в `docs/process/ai-mistakes.md`: что сделал не так, как заметили, как исправили.
3. Если изменился интерфейс — скриншот в `docs/process/screenshots/` с именем
   `YYYY-MM-DD-<экран>.png`, в том числе неудачные варианты.
4. Если принято архитектурное решение — новый файл в `docs/decisions/` со следующим номером.

Делай эти записи сам, в том же изменении, что и код. Не спрашивай, нужно ли.

## Соглашения

- Язык интерфейса, комментариев и документации — русский. Имена в коде — английские.
- Коммиты — от имени автора задачи, без строк атрибуции ИИ.
- Миграции БД — Alembic; seed тестовых данных — отдельный скрипт, идемпотентный.
- Перед тем как сказать «готово» — пройти сценарий руками: войти тестовым студентом,
  открыть экран, проверить на 360 px.
