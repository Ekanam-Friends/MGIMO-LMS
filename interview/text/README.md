# Текстовые расшифровки интервью

Расшифровки видео из `../raw/`. Сделано 22 ноября 2026.

## Как получены

1. Звук извлечён из видео через `ffmpeg` (моно, 16 кГц).
2. Речь распознана локально через `whisper.cpp`, модель `large-v3-turbo`, язык русский.
   Запись созвона с первого прогона распозналась как повтор фразы-заглушки. Помог повторный
   прогон с отключённым контекстом (`-mc 0`). Так же перепрогнаны два длинных уличных интервью.
3. Реплики разделены на интервьюера и респондента по смыслу (Claude Code). Явные ошибки
   распознавания исправлены: «Ранхикс» → РАНХиГС, «Митрикс» → Битрикс, «мудуль» → Moodle.
   Где слово не разобрать, стоит пометка [неразборчиво]. Мат заменён на [нецензурно].
4. Имена респондентов убраны: в тексте только курс и направление, как требует
   [гайд интервью](../../docs/research/interview-guide.md). Интервьюер — участник команды.

Метки времени — от начала соответствующего видео (мм:сс).
