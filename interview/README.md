# Видео интервью — 720p

Девять записей, добавленных по запросу Legpopov 21 ноября 2026.
Видео перекодированы в MP4 (H.264/AAC), без увеличения исходного разрешения:
до 1280×720 для горизонтального кадра, до 720×1280 для вертикального.
CRF 20, ограничение видеобитрейта до 6 Мбит/с; каждый файл меньше 2 ГБ.
Запись экрана сохранена с 30 кадрами/с; другие записи — с исходной частотой кадров.
Общий размер сжатых файлов — 797 265 137 байт (около 797 МБ).
Все записи полностью декодированы после сжатия без ошибок.

Файлы хранятся в Git LFS. Чтобы скачать их:

```sh
git lfs install
git lfs pull --include="interview/raw/**"
```

Исходные имена, размеры, длительность и SHA-256 сжатых файлов — в manifest.json.
Восстановить исходное качество из сжатых файлов нельзя.
По указанию пользователя после успешной загрузки, обратного скачивания и проверки
LFS локальные исходники, сжатые видео и их LFS-кэш удалены (15 387 005 018 байт).
В рабочей копии оставлены только LFS-указатели. Для просмотра скачайте видео из dev.

Материалы исключены из git archive и Docker-контекста. Production не обновлялся.
