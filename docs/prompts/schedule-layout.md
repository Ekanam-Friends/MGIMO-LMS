# Структура календаря в расписании

## 17 ноября 2026 — Legpopov

Запрос: «На странице расписание, расписание должно структурно быть таким же
как на главной странице». До реализации согласовано: недельная сетка слева,
навигация по датам внутри календаря, отдельная карточка «Мои календари» справа;
вместо плашек слоёв над сеткой использовать компоновку актуальной главной.
Сохранить переключение недель, фильтры, просмотр занятий и мобильный вид.
Пользователь подтвердил реализацию, коммит и push в текущую `fix/UX-UI`.

С первого раза: в `schedule.html` использованы существующие классы сетки
главной и общие partials календаря и его слоёв. CSS и серверная выборка
расписания не менялись. Мобильный список по дням сохранён.
Переработок реализации не потребовалось.

В изолированном стенде выполнен вход вымышленным студентом, открыт экран
расписания, проверены недельная сетка и правая карточка. После отключения
обязательных пар переход к следующей неделе сохранил выключенное состояние;
затем слой включён обратно. Проверена ширина `innerWidth = 360`, горизонтального
переполнения нет. Скриншоты: `2026-11-17-schedule-like-home-desktop.png` и
`2026-11-17-schedule-like-home-360.png` в `docs/process/screenshots/`.
В демонстрационной неделе занятий нет: визуальное содержимое карточек
занятий в этой браузерной проверке не оценивалось.
Проверка tests/test_web.py: 13 passed. Продакшен не изменялся.
