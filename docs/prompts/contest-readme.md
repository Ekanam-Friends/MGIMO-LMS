# Оформление README для жюри

**22 ноября 2026 · Legpopov**

Задача — оформить главную страницу репозитория для жюри. В начале нужны описание продукта и ссылка на стенд, затем выводы качественных интервью, сценарии проверки LMS и Pyrus, устройство кода с существующими схемами и краткая юнит-экономика с графиками.

За первый проход собрали пять разделов. Выводы привязали к своду трёх интервью, шаги для жюри сверили с документацией и кодом. Для архитектуры, справок и ассистента использовали готовые SVG, для экономики — два графика из расчёта в `economics/`. По уточнению Legpopov включили сценарии для всех ролей и сослались на существующую инструкцию с демо-доступами. При вычитке уточнили название этапа «Подпись декана» и путь к миграциям.

На демостенде вошли студентом из инструкции и при ширине 360 px открыли расписание, успеваемость, справки, задания и ассистента. Проверка ограничивалась входом и чтением страниц. Согласование в Pyrus и отправку уведомлений не запускали. Проверили 30 относительных ссылок и пять файлов изображений.
