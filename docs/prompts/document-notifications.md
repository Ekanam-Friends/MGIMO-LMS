# Уведомления о новом документе

## 16 ноября 2026

**Автор задачи:** Legpopov.

**Промпт:** «Надо настроить уведомление студентам при загрузке нового документа,
который их касается». В интервью согласовано: ИИ предлагает адресатов,
работник проверяет и подтверждает; каналы — личный кабинет и подключённый
Telegram. При сбое ИИ адресаты выбираются вручную. После успешной обработки
документа показывается число получателей, повторный запуск не создаёт новую
рассылку. Пользователь поручил реализовать и закоммитить в текущую ветку.

**С первого раза:** добавлены модели подтверждения и получателей, миграция,
валидация предложений GigaChat, ручной выбор и предпросмотр, уведомления в
ленте, очередь Telegram с фиксацией попыток и успеха. Персональные сведения
студентов не передаются ИИ. Для Telegram проверяется актуальность привязки.

**Уточнения по ходу:** изменён CSS поля ввода, чтобы он не растягивал радио-кнопки
поиска студента. При гонке предпросмотра показывается необходимость повторить
проверку вместо неясного возврата. Миграционный тест закреплён на вершине этой
фичи, чтобы его результат не зависел от параллельно добавляемой миграции языка.

**Проверки:** профильные тесты предложений ИИ, ручного сценария, границ доступа,
неизменности получателей, повторного подтверждения и Telegram-заглушки.
Ручной браузерный путь: предложение ИИ (демонстрационная заглушка), предпросмотр,
подтверждение работником, вход студента, появление и прочтение уведомления.
Экраны просмотрены на 360 px без горизонтального переполнения. Реальные API
GigaChat/Telegram и продовый сервер не использовались.
