# Исправления ревью #46 и #47

Дата: 22 ноября 2026. Постановщик: Legpopov.

Запрос: исправить замечания ревью, починить Ingress, проверить кандидата на рабочем
сервере до слияния в dev. После успешных проверок выложить и слить PR; main не обновлять.

Первый шаг: изолированная ветка, воспроизведение параллельного сброса кэша.
Исправление: сериализация отправок и отдельный токен каждого ожидающего сброса;
ответ Redis подтверждает только отправленную версию. Добавлен регрессионный сценарий
с двумя параллельными коммитами и ошибкой второго сброса.

Далее исправлены права административного kubeconfig (0600), таймаут ingress-nginx
(90 с), три TTL в ConfigMap и реестре ключей. При живом Linux-запуске найден CRLF
в экспортированном реестре: заданы LF и устойчивое сравнение полей awk.

Проверки: полный набор 330 passed, 4 skipped, 2 subtests passed; повтор Kubernetes
после CRLF-исправления — 8 passed. На VPS создан временный k3s в Docker с overlay
minikube и ingress-nginx. Запуск, миграции, seed, повторный запуск и вход трёх ролей
через Ingress прошли. Медленный backend вернул 200 через 65,06 с.

Свежий production-бэкап восстановлен в отдельной БД; страницы четырёх ролей,
межпроцессная инвалидация настоящего Redis и fail-open при остановке тестового Redis
прошли. До слияния в dev переключены web/bot; внешние HTTPS-проверки четырёх ролей,
Chromium 360 px, расписание, экран ассистента и выход прошли, ошибок JS нет.
Разрешённый пользователем публичный вызов GigaChat без доступа к БД: 12,097 с,
повтор из Redis — 0,001 с. Схема 0013_merge, реплика streaming, lag=0.

Что пришлось переделать: прерванный LFS checkout оставлен без сброса; создана
другая рабочая копия. Тестовый маршрут Ingress сначала опередил reload контроллера;
проверка повторена после подтверждения конфигурации. В мобильном тестовом драйвере
указан установленный Chromium и исправлена проверка URL как строки.
