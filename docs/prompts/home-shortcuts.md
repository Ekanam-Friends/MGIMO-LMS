# Кнопки главного экрана

## 17 ноября 2026 — Legpopov

Запрос: добавить справа внизу главной круглую красную кнопку с белой
четырёхконечной звездой для перехода на страницу ИИ-ассистента; справа
в верхней строке добавить смену языка. В коротком интервью уточнено:
кнопка ИИ нужна всем ролям, переключатель языка — только студентам.

Результат: общая оболочка показывает ссылку `/s/assistant` на главной
соответствующей роли. На телефоне ссылка размещена над нижним меню.
Студент выбирает один из четырёх существующих языков в верхней строке,
настройка сохраняется через прежний POST с CSRF. Новый параметр возврата
оставляет пользователя на исходной странице с её query-параметрами;
внешние адреса, обратные слэши и управляющие символы отклоняются.

С первого раза использованы существующие маршрут ассистента, языковые
словари и хранение настройки. После уточнения ролей условие кнопки ИИ
расширено на студентов; переводы сотрудников не добавлялись.

Проверка: 21 существующий тест языков и веб-интерфейса прошёл.
В локальной изолированной БД пройден вход вымышленным студентом,
переключение RU → EN → RU с сохранением главной и переход по кнопке ИИ.
В браузере проверена фактическая ширина `innerWidth = 360`, горизонтального
переполнения нет. Скриншот: `docs/process/screenshots/2026-11-17-home-assistant-language-360.png`.
После замечания пользователя изменения перенесены с устаревшей рабочей
ветки на актуальный `origin/dev` (`d119642`). Исходные правки из прежней
папки убраны обратным патчем. Сохранён неудачный снимок
`2026-11-17-home-shortcuts-before-dev-360.png`; актуальные снимки —
`2026-11-17-home-assistant-language-360.png` и
`2026-11-17-home-assistant-language-desktop.png`.
