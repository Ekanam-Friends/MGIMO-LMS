- **Кто ставил:** Legpopov.
- **Промпт:** «Изучи что делают отдельные сессии, сделай первые версии сайта (возьми с сайта
  ранха, потом поменяем) для того, чтобы какие-то решения можно было бы уже подключать
  (лк студента открыт в браузере)».

  → вход (настоящий сразу, а не заглушка) → какие разделы на живых данных (расписание,
  справки, профиль; остальное — каркасы) → как быть с незакоммиченной работой соседних
  сессий (сначала закоммитить справки отдельным коммитом).
- **Что сделал ИИ (Claude Code):**
  - просмотрел список сессий Claude Code и рабочую копию: расписание закоммичено, справки
    с Pyrus лежали незакоммиченными — прогнал их тесты (40 зелёных) и закоммитил отдельно;
  - открыл ЛК РАНХиГС в Chrome капитана и снял скриптом в консоли вычисленные стили
    (шрифт Manrope, фон `#F6F5F9`, акцент `#DF2935`, сетка главной 820 + 300 px, радиусы
    карточек 8/12 px, кнопка с радиусом `28px 3px`, таблица справок) — без персональных данных;
  - написал вход (argon2, серверные сессии, CSRF), миграцию 0004, идемпотентный seed,
    шаблоны Jinja2 + HTMX: главная с виджетом расписания (переключение дня без перезагрузки),
    расписание на неделю, справки (список, заказ, детали, ответ деканату, PDF, бумажный
    оригинал), профиль, 15 разделов-каркасов, мобильная шторка и нижняя панель;
  - 8 тестов: редирект без входа, неверный пароль, флаги cookie, «чужая группа не видна»,
    «чужая справка — 404», CSRF, выход, все страницы с плашкой концепта;
  - прошёл сценарий руками в браузере: вход `student1`, главная, переключение дня, заказ
    справки, расписание, меню на 360 px.
- **С первого раза:** вход, сессии, экраны и тесты (48 из 48 зелёных на первом прогоне).
- **Пришлось переделать:**
  - вёрстка показывала до 5 карточек на одну пару — параллельные языковые подгруппы; свернул
    их в одну карточку с раскрытием;
  - настройки cookie читались из `.env`, а не из настроек, переданных в `create_app` (см.
    ai-mistakes.md);
  - попытка сузить окно Chrome до мобильной ширины для снятия мобильной вёрстки РАНХиГС не
    сработала (окно развёрнуто) — мобильную схему взял по классам `tabbar` из DOM.
- **Скриншоты:** `docs/process/screenshots/2026-11-05-dashboard-desktop.png`,
  `2026-11-05-certificates-desktop.png`, `2026-11-05-dashboard-360.png`.
