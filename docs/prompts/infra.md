## 2026-11-09 — замена утёкшего ключа root на стенде

- **Кто ставил:** Legpopov. Повод — инструкция от Кости для кабинета преподавателя (PR #29)
  с пометкой, что в чат утёк приватный ключ `ikanam-schedule-deploy`. Промпты: «распиши мне
  пошагово, чтобы перевыпустить ключ», затем «сделай что можешь сам, что не можешь дай мне».
- **Что сделал ИИ (Claude Code):** выяснил, что утёкший ключ — это ключ входа root на стенд
  (импортирован с GitHub-аккаунта Legpopov) и ключ того же аккаунта GitHub. Проверил по
  `auth.log`, с каких IP по нему входили. Создал новый ключ на компьютере пользователя и
  прописал его в `~/.ssh/config`. После того как пользователь добавил публичную часть на
  сервер, проверил вход, убедился, что в `authorized_keys` root остался только новый ключ,
  удалил бэкап со старым и удалил старый ключ из аккаунта GitHub (`gh ssh-key delete`).
- **Что пришлось переделать:** первая инструкция была написана без указания, где выполнять
  команды, и очистила `authorized_keys` root (см. ai-mistakes.md).
- **Не сделано ИИ:** добавление нового ключа Кости. Автоматическая проверка прав запретила
  ИИ дописывать доступ в `authorized_keys`, команду выполнил пользователь.
