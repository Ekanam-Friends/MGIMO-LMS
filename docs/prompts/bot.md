# Telegram-бот

## 2026-11-05 — бот @Lms_university_ekanamfriends_bot по образцу ikanam_schedule_bot

- **Кто ставил:** Legpopov.
- **Промпт:** «Создал тг бота: @Lms_university_ekanamfriends_bot. Этот бот должен уметь всё,
  что умеет в бесплатной версии ikanam_schedule_bot, только для МГИМО в рамках хакатона,
  куда дать тебе ключ для бота?»
- **Ответ про ключ:** в чат не присылать; строка `TELEGRAM_BOT_TOKEN=` в `.env` (локально и на
  сервере), в репозитории — только `.env.example` без значения.
- **Интервью (скилл grillme), 3 вопроса:** как студент подключает бота (кнопка в профиле
  кабинета с одноразовой ссылкой, без пароля) → откуда расписание (из БД кабинета) → что
  обязательно в первой версии (ответ: «все сразу делай» — интервью на этом закончено).
- **Что сделал ИИ (Claude Code):**
  - прочитал исходники `lkanam-schedule` (команды, меню, настройки, календарь, планировщик,
    `.ics`) и отделил бесплатную часть от платной `/qr`;
  - нашёл, что в кабинете уже есть журналы для пушей (`lesson_changes`,
    `certificate_request_events.notified_at`), и построил уведомления на них, без своего диффера;
  - переписал бота на данные кабинета: привязка по коду, расписание с листанием, контрольные
    точки вместо дедлайнов СДО, подписка календаря с инструкциями по платформам, справки,
    настройки, `/status`, `/logout`; миграция 0005, контейнер `bot`, скрипт демонстрации пуша;
  - 8 тестов: одноразовость и срок кода, переезд привязки, полное удаление при отключении,
    профиль → t.me с кодом и CSRF, лента только своей группы и 404 после отключения, пуш об
    изменении только своей группе (и без рассылки истории), события справок, сводка;
  - проверил в браузере на 360 px оба состояния блока «Telegram-бот» в профиле и ленту `.ics`
    (442 события по группе student1).
- **С первого раза:** все 56 тестов зелёные на первом прогоне, миграция совпала с моделями
  (`alembic check`).
- **Пришлось переделать:**
  - кнопка «Открыть @Lms_university_ekanamfriends_bot» на 360 px переносилась в две строки —
    стала «Открыть бота»;
  - выражение адреса в `.ics` получилось запутанным — переписано до запуска.
- **Живая проверка (после того как капитан вписал токен):** бот запущен локально, капитан
  привязал свой Telegram по ссылке с кодом и прошёл все кнопки — 17 действий без ошибок;
  `demo_change` → сообщение о смене аудитории пришло примерно через минуту.
- **Выкладка:** коммит `fed8e0f`, `deploy.sh`. Выяснилось, что с VPS api.telegram.org
  недоступен напрямую — бот подключён к socks5-прокси Ikanam через серверный override.
  Сборка шла медленно, ssh оборвался посреди неё — сборка перезапущена на сервере через
  `nohup`. Ошибка с одноимённым сервисом `db` в сети Ikanam — в ai-mistakes.md.
