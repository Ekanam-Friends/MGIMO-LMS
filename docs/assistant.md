# ИИ-ассистент: состояние на 16 ноября 2026

Чат развёрнут на https://lms-university.ekanamfriends.ru/s/assistant.
Есть интерфейс для компьютера в палитре кабинета, диалог с полем ввода внизу
и мобильный вариант. Перед использованием нужно подтвердить предупреждение
об ошибках ИИ. Данные успеваемости читаются только после отдельного разрешения
в чате; «Новый чат» отзывает его. Расписание относится к группе, подгруппа
подписана в занятиях. Ассистент не изменяет данные и не создаёт заявки.

## Поиск и GigaChat

- Провайдер — GigaChat API; OAuth и TLS с проверкой сертификатов.
- Генерация: `GigaChat-2`, использует доступные бесплатные токены проекта.
- Поиск: BM25 по словам и их формам. Векторный поиск не включён.
- `RAG_USE_EMBEDDINGS=false` в серверном окружении и по умолчанию в коде.
  По просьбе Legpopov платные эмбеддинги не используются. Четыре доступные
  embedding-модели при проверке вернули HTTP 402; текстовая генерация — HTTP 200.
- Один одновременный вопрос на процесс (`RAG_CONCURRENT_REQUESTS=1`),
  что соответствует одному потоку Freemium. До шести вопросов пользователя в минуту.
- Для личных данных модель выбирает идентификаторы фактов; текст ответа и
  ссылки формируются сервером. ФИО, контакты, цели справок и комментарии не передаются.

На сервере заданы `LLM_PROVIDER`, `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE`,
`GIGACHAT_MODEL`, `GIGACHAT_CA_BUNDLE`. Секреты находятся в
`/opt/mgimo-lms/.env`, не в репозитории. Сертификаты — в
`/opt/mgimo-lms/data/ca/gigachat-ca.pem`, внутри контейнера `/data/ca/gigachat-ca.pem`.

## Корпус и ограничения

Исходные 27 PDF находятся в `/opt/mgimo-lms/data/regulations`. В PostgreSQL `lms`
на момент проверки были 33 таблицы кабинета, без таблиц НПА или векторов:
эти документы хранятся как файлы, а не как записи PostgreSQL.

OCR выполнен локально через Tesseract `rus+eng`. Результаты и изображения первых
страниц сохранены в `/opt/mgimo-lms/data/regulations-review`. Локальная LLM
не устанавливалась. Рабочий JSONL содержит 862 фрагмента из всех 27 документов;
отчёт — [assistant-corpus-2026-11-16.json](process/assistant-corpus-2026-11-16.json).

Это **справочный загруженный снимок**, а не подтверждённый набор действующих
редакций. Дата загрузки в исходном манифесте — 10 ноября 2026; точные даты
действия не выдумывались и хранятся как `null`. Полная сверка OCR с изображениями
всех страниц не выполнена. При повторной проверке оригинала сайт МГИМО вернул
HTTP 200 с HTML-защитой вместо PDF; этот ответ не принят за подтверждение документа.

Такие фрагменты имеют `verification_status=snapshot`, доступны только для
текущего справочного запроса и всегда дают статус `partial` с предупреждением.
Номера пунктов, которые OCR мог распознать неверно, не выдаются за проверенные:
ссылка содержит номер фрагмента и страницу/диапазон страниц PDF. При отсутствии
применимых выдержек — отказ. Для исторических ответов требуются отдельно
проверенные редакции, даты и основание обратной силы.

## Повторная подготовка

OCR-инструмент: `scripts/rag/Dockerfile` и `scripts/rag/extract.py`.
Он получает `/corpus` только для чтения, результаты пишет в `/review`.
Публикация справочного BM25-снимка, без вызовов эмбеддингов:

```sh
PYTHONPATH=. python scripts/rag/publish_snapshot.py \
  --review /data/regulations-review --out /data/regulations --lexical-only
```

Скрипт проверяет хэши оригиналов, соединяет пункт при переходе между страницами,
проверяет новый JSONL целиком и атомарно заменяет рабочий индекс. Базовая команда
также работает без эмбеддингов; для них существует отдельный явный флаг, который
в текущем развёртывании не используется. Кэш векторов привязан к тексту и модели.

## Полностью локальная обработка НПА сотрудников

RAG можно адаптировать для всех локальных НПА, доступных сотруднику, с поиском
и генерацией локально на сервере. Это расширение не входило в задачи хакатона,
поэтому локальная модель не развёрнута. Для него нужны локальные модели генерации
и эмбеддингов, права на документы на уровне поиска, внутренние ссылки и отдельная
проверка качества. Текущий GigaChat API-вариант не является полностью локальным.

Решение по разрешениям и ограничениям — [0015](decisions/0015-assistant-consent-personal-data.md).
