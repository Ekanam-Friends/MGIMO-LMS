Дата: 2026-11-05. Источник: живой ЛК https://my.ranepa.ru/lk/student, его открывал капитан
(Legpopov) под своей учёткой. Персональные данные из ЛК сюда не переносились.

## Справки и выписки

Заказ идёт в два шага: место обучения, затем **категория → тип**, раскрывающееся описание
и дополнительные поля.

| Категория | Тип | Доп. поля | Выдача |
|-----------|-----|-----------|--------|
| Справка | Справка, подтверждающая факт обучения | — | Электронно с ЭП или на бумаге |
| Справка | Справка-вызов (учебный отпуск у работодателя) | Работодатель, цель компенсации, даты начала и окончания | Электронно, бумага по запросу |
| Справка | О размере стипендии, форме и стоимости обучения (субсидии, соцльготы) | Период: начало и конец | Электронно, бумага по запросу |
| Справка | О периоде обучения (для перевода в другой вуз) | Организация, куда переводится студент | **Только бумага**, бланк строгой отчётности, до 5 раб. дней, лично или по доверенности |
| Справка | Для налогового вычета за обучение | — | Заказа нет, только памятка |
| Выписка из приказа | О зачислении | — | Электронно, бумага по запросу |
| Иные документы | Выписка из электронной зачётной книжки (заменила справку об успеваемости с 10.03.2025) | — | Электронно, бумага по запросу |

**Сроки:** электронная справка — не более 2 рабочих дней, бумажная — не более 1 рабочего дня
после запроса.

Что из этого стоит перенять:

1. **Сначала электронная справка, бумага по запросу.** Бумажную копию можно заказать только
   после скачивания электронной, забирать её надо лично в студенческом офисе.
2. **Два независимых статуса** у одной заявки:
   - электронный: «Готова в электронной форме», «Истечение срока выдачи» с комментарием
     сотрудника; у скачивания есть срок («Срок скачивания истёк»);
   - бумажный: кнопка «Выдать на бумажном носителе» → «Готова к выдаче» → «Выдана на бумажном
     носителе» или «Не востребована»; до скачивания электронной — «Будет доступно после
     скачивания электронной справки».
3. **Кнопка «В моей справке есть ошибка»**: перезаказ с пометкой об ошибке.
4. **Защита от дублей**: «Вы уже создали заявку на такую справку».
5. **Комментарий сотрудника** к заявке (значок в строке таблицы).
6. Блок о **проверке ЭП** через госсервис и о справках, которых нет в списке: их статус
   приходит на почту.

## Заявления (студенческий офис)

Работают по той же схеме (категория → тип). Есть статус «Возвращено для внесения изменений»
с действием «Внести изменения», это аналог нашего «Нужна информация».

| Категория | Типы |
|-----------|------|
| Отчисление | В связи с переводом в другой вуз; по собственному желанию |
| Изменение ФИО или гражданства | Изменение ФИО и/или гражданства |
| Академический отпуск | Академический; по уходу за ребёнком; по беременности и родам |
| Оплата обучения | Отсрочка; рассрочка; скидка |
| Выдача дубликатов | Дубликат студенческого билета |
| Экзамены и пересдачи | Каникулы после ГИА; досрочная аттестация; пересдача для повышения оценки; специальные условия на аттестации |
| Переводы и восстановления | На другую форму; с платного на бюджет; в другое подразделение; на другую программу |
| Индивидуальный порядок посещения | Предоставление; отмена |
| Стипендии и мат. помощь | Социальная стипендия; материальная помощь |
| Общежитие | Включение в реестр нуждающихся; новые достижения (уже в реестре) |

## Что это значит для MGIMO-LMS

- **Каталог видов справок** для seed и шаблонов PDF берём из таблицы выше (адаптируя
  названия), а не придумываем.
- **Статусы в ЛК.** Разделить электронную справку и бумажный оригинал так, как сделано
  в РАНХиГС. Это уточняет наш финальный статус «Готова» из решения 0003 и требует отдельного
  решения.
- **Сценарии ИИ-ассистента** напрашиваются сами: «закажи справку-вызов для работодателя на
  сессию с 12 по 25 января» — ассистент заполняет доп. поля из расписания сессии.
