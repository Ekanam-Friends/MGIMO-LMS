# 0006. Календарь из трёх слоёв — центральный объект кабинета

Дата: 6 ноября 2026. Статус: принято.
Источник: скриншот Google Calendar с пометками от Legpopov: «1 — возможность включения в
календарь 1) пар обязательных 2) элективов 3) внеучебных активностей, на которые подписался
студент; на месте прямоугольников будут события, это должен быть центральный объект на
странице», затем интервью (скилл grillme) и уточнение «популярные сервисы должны находиться
там, где сейчас расписание».

## Решения

| Вопрос | Решение |
|--------|---------|
| Где календарь | **И на главной, и в «Расписании».** На главной — компактная неделя в центре, «Популярные сервисы» переехали в правую колонку на место дневного расписания. На `/schedule` — та же неделя крупнее |
| Слои | «Мои календари» слева: обязательные пары, элективы и подгруппы, внеучебные активности. Чекбоксы прячут слой чистым CSS (`:has`), выбор помнит `localStorage`; при листании недель меняется только сетка (`#cal-main`), поэтому чекбоксы не сбрасываются |
| Что считать элективом | В РУЗ занятия по выбору не помечены. Признак берётся из данных группы: у занятия есть подгруппа (языки) **или** в то же время у группы идёт другая дисциплина без подгруппы (параллельные курсы). Параллельные дисциплины связываются в «блоки по выбору». Занятия-объединения с чужими группами (`a; b`) отдельным вариантом не считаются |
| Как студент выбирает | Раздел «Элективные дисциплины» (`/electives`, был заглушкой): галочки подгрупп и курсов из расписания его группы. Невыбранные занятия по выбору в календаре не показываются. Принимаются только варианты из расписания своей группы |
| Внеучебные активности | Вымышленные, из seed (еженедельные клубы на семестр и разовые события). Записанные — яркие, остальные — бледные с пунктиром. Клик по любому событию раскрывает карточку (нативный `popover`: название, время, аудитория); у активности в карточке кнопка «Записаться» / «Отменить запись» (HTMX, CSRF). Без JS работает обычной формой с редиректом на свою страницу (белый список, не открытый редирект) |
| Телефон (360 px) | Сетка не помещается — остаётся **список** (день на главной, неделя на `/schedule`) с цветной меткой слоя и кнопкой «Записаться» у активностей |
| Telegram и `.ics` | Пока без изменений: бот и лента подписки показывают все пары группы. Учесть выбор элективов и записи на активности — отдельная задача |
| Данные | Таблицы `elective_choices`, `activities`, `activity_signups` (миграция 0006). Seed ставит демо-выбор и демо-записи, только если студент ещё ничего не выбрал сам |
| Кэш стилей | `app.css` подключается с `?v=<mtime>`, иначе после выкладки браузер показывал страницу со старыми стилями |

## Последствия

- Идея «без очередей в деканат» не затронута: блок «Деканат» и справки остались на главной ниже календаря.
- В данных РУЗ встречаются настоящие пересечения (лекция без подгруппы и язык выбранной подгруппы
  в одно время) — календарь показывает их рядом, не скрывая.
