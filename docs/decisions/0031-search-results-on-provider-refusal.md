# 0031. Результаты поиска при отказе GigaChat выбрать выдержки

22 ноября 2026 года. Решение принято.

Вопрос о последствиях поступка использует отдельные поиски требования и возможных мер. Если GigaChat явно отказывается выбрать цитаты, сервер показывает по одному лучшему совпадению из каждого поиска, которое вошло в контекст. Выдержки берутся из публичного корпуса с учётом даты редакции. Порядок остаётся поисковым, а применимость норм к ситуации требует проверки.

Режим `sources_only` не меняет требования аудита к обычному ответу. Поисковые совпадения из него не сохраняются в контексте диалога и кэше ответов. Сетевые сбои, ошибки формата, отказ на этапе маршрутизации и отказ аудита обрабатываются прежним образом.
