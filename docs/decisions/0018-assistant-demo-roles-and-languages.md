# 0018. Доступ к демо-студентам и языки кабинета

Дата: 16 ноября 2026. Решение принято по интервью с Legpopov.

Студент видит только собственные данные. Преподаватель и сотрудник в демонстрации
могут выбрать любого вымышленного студента, включая его расписание, успеваемость и
заявки. Это прямое требование демонстрации, а не модель полномочий рабочей системы.
Выбор закреплён сервером за беседой, модель не может сменить студента по имени или id.
Смена требует новой беседы и повторного согласия на оценки. Изменение роли аккаунта
делает прежнюю беседу недоступной.

Расширенный доступ включается только настройкой `ASSISTANT_DEMO_STUDENT_ACCESS=true`
в среде с вымышленными данными; по умолчанию он выключен. Всем трём ролям доступны
публичные НПА и обязательное предупреждение об ошибках ИИ. В интерфейсе прямо указано:
реальные учебные данные должны обрабатываться локально на сервере; в демоверсии
вымышленные записи обрабатываются GigaChat, локальная модель не развёрнута.

Для студентов язык интерфейса сохраняется в аккаунте: русский, английский,
французский, китайский (упрощённые иероглифы). Смена защищена CSRF. Язык беседы
фиксируется при её создании; преподавателям и сотрудникам оставлен русский.

Статические надписи переводятся локальными словарями, без API при показе страниц.
Вопрос иностранного студента переводится для поиска по русскому корпусу, найденные
выдержки и факты получают отдельный справочный перевод. Оригиналы, источники,
номера страниц и статусы проверки сохраняет сервер. Машинный перевод требует
проверки по оригиналу и не становится новой нормативной редакцией.

Поиск остаётся BM25. Платные эмбеддинги не используются.
