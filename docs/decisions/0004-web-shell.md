# 0004. Первая версия сайта: вёрстка по образцу ЛК РАНХиГС, настоящий вход

Дата: 5 ноября 2026. Статус: принято (вёрстка — временная).
Источник: интервью с капитаном (скилл grillme) перед задачей «сделай первые версии сайта,
чтобы решения других сессий уже можно было подключать».

## Контекст

К этому моменту были готовы бэкенды расписания (импорт РУЗ, [0002](0002-schedule-source.md))
и справок через Pyrus ([0003](0003-dean-office-pyrus.md)), но не было ни одного экрана и
входа. Подключать новые решения было некуда.

## Решения

| Вопрос | Решение |
|--------|---------|
| Насколько повторять ЛК РАНХиГС | **Максимально близко («пиксель в пиксель»)**: та же сетка, размеры, шрифт Manrope, цвета, порядок меню. Потом меняем по частям. Размеры и цвета сняты из живого ЛК через DevTools-скрипт, см. [docs/research/ranepa-lk.md](../research/ranepa-lk.md) |
| Что не копируем | Логотип, фотографии, иконки и тексты РАНХиГС — свои линейные иконки, нейтральный знак «ЛК студента · концепт». Плашка «Концепт для конкурса… не официальный сервис» на каждой странице. Персональные данные из ЛК капитана никуда не переносились |
| Вход | **Настоящий сразу**: таблицы `users` и `auth_sessions` (миграция 0004), пароли argon2, серверные сессии. В cookie — случайный токен, в БД — его SHA-256. Cookie `HttpOnly`, `SameSite=Lax`, `Secure` (отключается только `COOKIE_SECURE=false` для локального http) |
| CSRF | Токен на сессию, проверяется на всех POST кабинета (поле `csrf` в форме или заголовок `X-CSRF-Token`, который HTMX ставит сам через `hx-headers` на `<body>`) |
| Живые данные | Расписание (по группе студента из БД), справки (сервис из `app/certificates`), профиль (`students`). Остальное — страницы-каркасы `/s/<slug>` с описанием, что туда подключится (`app/web/nav.py`) |
| Тестовые учётки | `python -m app.seed`, идемпотентно: `student1` (3-й курс, группа 24МЖ-02), `student2` (2-й курс, 25МО-24), `dean` (сотрудник). Группы — реальные из РУЗ, чтобы расписание было живым; ФИО, зачётки, приказы — вымышленные. Пароль — `DEMO_PASSWORD` из `.env`, в коде его нет |
| Параллельные занятия | В группе одновременно идут занятия разных языковых подгрупп (до 5 карточек на одну пару). Сворачиваем их в одну карточку «Занятия по подгруппам» с раскрытием |
| Мобильная версия | До 1024 px меню уезжает в шторку (чистый CSS, чекбокс), снизу панель из 4 разделов, как tabbar в ЛК РАНХиГС. До 640 px таблица справок превращается в карточки. Проверено на 360 px: горизонтального скролла нет |

## Как подключать новое

- **Новый раздел**: роут в `app/web/views.py` (или свой роутер), шаблон в `app/web/templates/`,
  наследующий `base.html`; в `app/web/nav.py` поменять `href` пункта меню с `/s/<slug>` на
  настоящий и удалить запись из `STUBS`.
- **Данные студента**: только через `viewer.student_id` из зависимости `current_viewer` — он
  берётся из сессии. Параметры запроса для выбора студента или группы не используются.
- **POST-формы**: зависимость `check_csrf` и `<input type="hidden" name="csrf" value="{{ viewer.csrf }}">`.
- **Виджеты главной**: «Текущая успеваемость» и «Средний балл» — заглушки в
  `dashboard.html`, ждут раздела «Успеваемость».

## Допущения и открытые вопросы

| Что | Статус |
|-----|--------|
| Студент видит все языковые подгруппы своей группы, а не только свою | предположение: нужна привязка студента к подгруппе, данных о ней в РУЗ по студентам нет |
| HTMX грузится с unpkg (`htmx.org@1.9.12`), Manrope — с Google Fonts | не проверено, доступны ли они с VPS и у жюри; при проблемах — положить в `static/` |
| Близость к РАНХиГС не создаёт риска «копирования чужого сервиса» | смягчено: свой знак, плашка концепта, свои иконки; к финалу вёрстку меняем под МГИМО |
