# 0007. Основа для ИИ-ассистента с поиском по положениям (RAG): корпус, ключи, хранение

Дата: 10 ноября 2026. Статус: принято для подготовки; сам ассистент пишет Келли.
Источник: Legpopov — «Келли хочет сделать RAG на помощнике. Что нужно, чтобы подготовить
почву, скачать все файлы положения МГИМО?», затем интервью (скилл grillme).

## Решения

| Вопрос | Решение |
|--------|---------|
| Что должен знать ассистент | Положения МГИМО, «всё по уставу». Для демо жюри — **студенческое ядро** на 15–30 документов (академ, перевод, отчисление и восстановление, стипендии, общежитие, ГИА, БРС, правила внутреннего распорядка); остальное расширяем по приоритетам |
| Источник | Публичный сайт mgimo.ru. Внутреннего контура нет. Положение о скидках на платное обучение (приказ 825, ред. от 27.04.2026) уже есть у Legpopov локально; остальные студенческие положения надо качать с нуля |
| Чего в корпусе быть не может | Приказов о зачислении и других документов с ФИО абитуриентов и студентов: по правилам задания данные только вымышленные. Старые редакции и страницы Wayback в индекс не идут |
| Актуальность | Скрипт сравнивает версию на сервере сайта с локальной и перекачивает документ, если на сайте новее. У каждого файла хранится `meta.json`: URL, дата скачивания, хэш, номер и дата приказа. В ответах ассистент указывает документ и редакцию |
| Где лежит корпус | На сервере в `/opt/mgimo-lms/data/regulations/`, вне репозитория и вне образа; монтируется в `web` и `bot` как `/data/regulations`. Монтирование задаёт root в серверном `docker-compose.override.yml`: `deploy` Келли `docker-compose*.yml` из архива выбрасывает намеренно |
| Ключи LLM | Только в `/opt/mgimo-lms/.env` на сервере (переменные — в `.env.example`). Провайдер GigaChat или YandexGPT выбирается `LLM_PROVIDER`; пока не задан, ассистент выключен |
| Эмбеддинги | Через API провайдера. Локальные модели (`torch`, `sentence-transformers`) не берём: сборка образа на сервере идёт ~50 КБ/с |
| Хранение векторов | **Старт без `pgvector`:** текст фрагментов и эмбеддинги в обычных таблицах Postgres (миграция Alembic), для 20–30 документов хватает. `pgvector` — необязательное усложнение, см. «Риски» |
| Права Келли | Не меняются: `deploy`, `run app.<модуль>`, `logs`, `restart`, `psql` для разработки ассистента достаточно. В группу `docker` не добавляется (это root на всём VPS, включая Ikanam) |

## Риски и ограничения

- **Образ БД менять нельзя «на месте».** `postgres:16-alpine` → `pgvector/pgvector:pg16` — это
  другая сборка (musl → glibc) с теми же файлами данных: порядок сортировки строк может
  отличаться, индексы по тексту — повредиться. Если `pgvector` понадобится, процедура —
  дамп (`pg_dump`), новый том, восстановление; не подмена образа над старым томом.
- **Сертификат Минцифры для GigaChat.** С сервера доступность GigaChat/YandexGPT и нужность
  сертификата не проверены. Проверить: `curl` из контейнера `web` на эндпоинт провайдера.
- **Ключ видит каждый, у кого есть `shell web`:** секреты лежат в окружении контейнера. Это
  принято: ассистента пишет участник команды. Если понадобится строже, убрать `shell` из
  обёртки `scripts/server/mgimo-lms`.
- **Ассистент не официальный источник.** Ответ без найденного фрагмента — «не нашёл в
  положениях, обратитесь в деканат», а не догадка. Плашка «концепт для конкурса» остаётся.

## Открытое

- Как Келли получает файлы на сервер: скачивает скриптом прямо на сервере (нужен выход к
  mgimo.ru, не проверен) или заливает по SFTP. Обёртка пока умеет только то, что описано в
  [deploy.md](../deploy.md).
- Критерий приёмки (предложение): 10 контрольных вопросов по ядру — верный ответ с указанием
  документа; на вопрос вне корпуса — честный отказ.
