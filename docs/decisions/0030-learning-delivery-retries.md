# 0030. Очередь Telegram для учебных событий

**Дата** — 22 ноября 2026 года.

Лента ЛК хранит и события, созданные до подключения новой доставки.
Оценки поступают в очередь через сервис успеваемости, который задаёт время первой попытки.
Миграция оставляет это поле пустым у старых строк. Их по-прежнему видно в ЛК.

Задания, сообщения и оценки с временной ошибкой получают время следующей попытки.
При ограничении Telegram бот использует переданную сервером задержку, при прочих временных
сбоях ждёт пять минут. Постоянная ошибка завершает доставку отдельной записи.
Блокировка строки в PostgreSQL сохраняется до фиксации результата попытки.
