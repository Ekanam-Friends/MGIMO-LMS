# 0012. Подтверждение покрытия семестра по группе

Дата: 2026-11-16. Статус: принято. Уточняет [0011](0011-schedule-bootstrap.md)
по результатам ревью PR #35.

Наличие занятия не подтверждает загрузку семестра: оно могло прийти из короткого
периодического импорта или относиться к прошлому учебному году. Общий `import_runs`
не хранит список успешно загруженных групп, поэтому восстановить покрытие старых
импортов достоверно нельзя.

Добавляем `group_schedule_coverage` (миграция 0010): ключ — группа и начало семестра,
поля — конец периода и id импорта. Импортёр записывает подтверждение только при
непустом успешном импорте полного семестра, в одной транзакции с занятиями группы.
Bootstrap учитывает подтверждения завершённых `ok`/`partial` запусков, курсы 1–6
и наличие активных занятий в текущем семестре. Короткий импорт подтверждение не стирает.

Исторические импорты без подтверждений проверяются повторной загрузкой один раз.
Наличие старых занятий само по себе не переносится в новую таблицу. При недоступном
РУЗ прежнее расписание остаётся в базе, покрытие не выдумывается.

Цель bootstrap — число непустых групп. Импортёр добирает кандидатов ограниченными
пакетами, пока цель не достигнута или кандидаты не закончились; пустые ответы и ошибки
цель не расходуют. При исчерпании кандидатов пишется предупреждение. CLI сохраняет
прежнюю семантику `limit` — ограничение числа попыток.

При догрузке запрещаем журналировать `added`, в том числе для частично загруженных
групп, чтобы расширение окна не породило массовую рассылку. Переносы, изменения,
восстановления и отмены уже известных занятий продолжают обрабатываться.
