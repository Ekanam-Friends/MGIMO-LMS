# 0016. Загрузка публичных документов сотрудником

Дата: 16 ноября 2026. Статус: принято для реализации задачи пользователя.

Работник добавляет новый PDF в базу знаний ассистента из `/d/documents`,
доступного с главной деканата. Автор определяется по серверной сессии с ролью
`staff`; отдельный профиль работника для этого сценария не требуется.

## Решения

- `KnowledgeDocument` хранит оригинал PDF в БД, автора, название, источник,
  редакцию, хэши, состояние, время загрузки и результат обработки. Очередь
  переживает перезапуск приложения. Схема вводится Alembic `0010_documents`
  от `0009` — текущей вершины миграций этой ветки. При объединении с веткой,
  содержащей отдельную `0010`, нужно согласовать граф миграций.
- Работник подтверждает сверку с публичным оригиналом и отсутствие закрытых
  данных. Допустимы только HTTPS-источники mgimo.ru и его поддоменов; сервер
  не скачивает переданный URL. Текст предназначен для внешнего GigaChat.
- Одна кнопка загрузки запускает автоматическую обработку. Отдельного шага
  ручной публикации нет. Статусы: `queued`, `processing`, `published`,
  `needs_review`, `error`.
- Один обработчик в одном процессе web последовательно извлекает текст и
  дополняет существующий `chunks.jsonl`. Новый снимок целиком проверяется
  через `Corpus.load`, затем заменяется атомарно. Ассистент перечитывает файл
  при запросах, перезапуск для новой загрузки не требуется.
- После сбоя `processing` возвращается в очередь. Повтор после публикации
  до фиксации результата в БД не добавляет копии фрагментов. Ошибка сохраняет
  предыдущий рабочий снимок. Параллельная публикация CLI во время работы
  обработчика и несколько процессов web не поддерживаются.
- Максимум 10 МБ, 100 страниц, без пароля, с текстовым слоем. Сканы требуют
  внешнего OCR и сверки. Исправленный файл по той же ссылке может заменить
  неуспешную загрузку; опубликованную редакцию интерфейс не заменяет.
- Новые фрагменты имеют `verification_status=snapshot`, без выдуманных дат
  действия. Проверка публичности датируется загрузкой, а не повторным запуском
  очереди. Существующее ограничение свежести корпуса продолжает действовать.
- Используется текстовый BM25-поиск, без платных эмбеддингов. При включённом
  `RAG_USE_EMBEDDINGS` обработчик возвращает явную ошибку вместо публикации
  несовместимых фрагментов.

## Эксплуатация

Нужны миграция, зависимость `.[rag]` и доступ на запись в `RAG_CORPUS_DIR`.
Dockerfile устанавливает PyMuPDF и создаёт доступный пользователю `lms`
каталог `/data/regulations`. Для сохранности индекса между пересозданиями
контейнера нужен постоянный том/существующее серверное монтирование `/data`.
Оригиналы находятся в БД и должны включаться в её обычные резервные копии.
Изменений на проде этой задачей не выполнялось.
