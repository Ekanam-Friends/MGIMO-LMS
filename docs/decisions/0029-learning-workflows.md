# 0029. Учебные сценарии по итогам интервью

Дата: 22.11.2026. Статус: принято по согласованию с Legpopov.

Повторные вопросы и ручной учёт посещаемости нагружают старост. Задания используют
существующие Assessment и Score; новые таблицы хранят решения, сообщения, адресные
уведомления и отметки. Файлы до 10 МБ хранятся в PostgreSQL как в текущем корпусе
документов; загрузка файла отложена до авторизованного скачивания.
Транзакция записи создаёт уведомления; бот отправляет после фиксации записи.
Окно отметки относится к Lesson, доступ проверяется по lesson_teachers и LessonGroup
с учётом выбора элективов. Срок — 90 секунд, пять попыток; исправления журналируются.
Код не доказывает физическое присутствие: пересылка принята как ограничение прототипа.
Уменьшение нагрузки — гипотеза, требует проверки после пилота.
