Источник: сократовское интервью с капитаном команды по открытым вопросам из README.

## Решения

### Продукт

| Вопрос | Решение |
|--------|---------|
| Обязательное ядро | Все пять разделов: вход и профиль, расписание, успеваемость, заявки и справки, уведомления |
| Главная фишка | **ИИ-ассистент деканата** |
| Вторая фишка | **Интеграция с календарём и Telegram** |
| Кабинет сотрудника | ~~**Да, минимальный**: список заявок и кнопки «в работе / готово / отказ»~~ **Заменено [0003](0003-dean-office-pyrus.md)**: свой кабинет не делаем, сторона деканата — настоящий Pyrus, жюри получает тестовый логин в Pyrus |
| Данные расписания | **Парсинг открытого расписания МГИМО**. Дисциплины, время и аудитории — с сайта; **ФИО преподавателей детерминированно заменяются на вымышленные при импорте** (задание запрещает реальные ФИО) |

### ИИ-ассистент

| Вопрос | Решение |
|--------|---------|
| Провайдер | **GigaChat или YandexGPT** — доступны с хостинга в РФ без прокси |
| Ключ | Только на бэкенде, в переменных окружения. В клиент не попадает |
| Способности (полный список) | 1) отвечать по данным текущего студента; 2) действовать — создавать заявки, ставить напоминания; 3) FAQ по регламентам деканата |
| Приоритет при нехватке времени | **Действия (заказ справки)** — остальное в «если успеем». Действия неявно требуют чтения данных студента, поэтому п. 1 реализуется как база для п. 2 |
| Безопасность | Ассистент получает инструменты (tool calls), которые работают только от имени авторизованного студента: id студента берётся из сессии, не из запроса модели |

### Telegram и календарь

| Вопрос | Решение |
|--------|---------|
| Объём | **Полный бот-двойник кабинета**: расписание, заявки, уведомления из бота. Выбран осознанно, с пониманием риска по срокам (см. «Риски») |
| Повторное использование | `.ics`-подписка и диффер расписания переносятся из Ikanam-schedule |

### Безопасность

| Вопрос | Решение |
|--------|---------|
| Аутентификация | **Серверные сессии + cookie** (HttpOnly, Secure, SameSite=Lax) |
| Пароли | Хэш argon2 или bcrypt, в открытом виде не хранятся |
| Авторизация | Проверка владельца на каждом запросе к данным студента (заявка, оценки, профиль) — на уровне запроса к БД, не только в UI. Подстановка чужого id в адрес возвращает 404 |
| Роли | Две с первого дня: `student`, `staff` |
| Секреты | `.env` вне репозитория, в репо — `.env.example` без значений |
| Данные | Только вымышленные: студенты, оценки, зачётки. Минимум два тестовых студента с заметно разными данными плюс аккаунт сотрудника |

### Хостинг и деплой

| Вопрос | Решение |
|--------|---------|
| Сервер | Боевой VPS Ikanam-schedule |
| Изоляция | **Отдельный docker-compose, отдельный контейнер PostgreSQL, своя docker-сеть**. Общий с ботом — только Caddy |
| Вход (reverse proxy) | **Один общий Caddy на стандартных портах 80/443**; в его конфиг добавляется блок для домена прототипа, Caddy подключается к сети прототипа. Второй Caddy на том же сервере невозможен без нестандартных портов |
| Нестандартные порты | **Отклонено**: ссылка с портом, часть мобильных сетей режет такие порты, автоматический HTTPS от Let's Encrypt требует 80/443 |
| Домен | Отдельный домен в зоне `.online` |

### Процесс с ИИ (критерий «Масштаб нейротехнологий»)

| Вопрос | Решение |
|--------|---------|
| Где ведём | **В репозитории по ходу работы**: `docs/prompts/` — ключевые промпты по функциям, `docs/process/` — скриншоты и ошибки ИИ, `docs/decisions/` — решения |
| Механика | **Правило в `CLAUDE.md`**: задача не считается сделанной, пока ИИ-агент не добавил запись в `docs/prompts/` и, при ошибке, в `docs/process/ai-mistakes.md` |
| Итоговый документ | PDF собирается в конце из материалов репозитория |
| Дата заморозки фич | **Не назначена** — осознанное решение капитана |

## Допущения

| Допущение | Статус |
|-----------|--------|
| Реалии деканата МГИМО (факультеты, виды справок, сессия) соберём из открытых источников | не проверено, источник не назван |
| HTMX даст достаточно «приложенческий» мобильный UI для критерия «Качество» | не проверено |
| На VPS хватит ресурсов на второй PostgreSQL и приложение рядом с ботом | не проверено — замерить RAM/CPU до деплоя |
| Расписание МГИМО доступно в парсируемом виде | **подтверждено 2026-11-05** — открытый JSON-API РУЗ, см. [0002](0002-schedule-source.md) |
| GigaChat/YandexGPT дают tool calling достаточного качества для «действий» | не проверено |

## Риски и митигация

| Риск | Митигация |
|------|-----------|
| Максимальный объём (бот-двойник, ассистент с действиями, кабинет сотрудника, парсер) без даты заморозки при главном названном риске «слабый документ процесса» | Документ пишется по ходу через правило в CLAUDE.md, а не в конце. Если к 18 ноября ядро не проходится на телефоне без ошибок — бот-двойник сокращается до уведомлений + .ics |
| Реальные ФИО преподавателей в спарсенном расписании | Замена на вымышленные на этапе импорта, проверка seed-данных перед деплоем |
| Деплой рядом с боевым ботом | Отдельный compose и БД; перед деплоем — замер ресурсов; откат — удаление блока из Caddy |
| Роли не разделены → дублирование работы | Канбан с назначением исполнителя на каждую задачу |
| Ключ LLM утечёт в клиент | Все вызовы LLM только через бэкенд, ревью PR на наличие ключей, `.env` в `.gitignore` |
