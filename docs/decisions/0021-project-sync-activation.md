# 0021. Проверка синхронизации до включения записи по расписанию

Дата: 17 ноября 2026. Статус: принято по ревью PR #40.

Ручная проверка доступна независимо от PROJECT_SYNC_ENABLED. Расписание требует
явного true, причём это проверяют и workflow, и сценарий запуска скрипта.
Чистая функция workflow_mode определяет skip, dry-run или apply без обращения
к GitHub. Неизвестные события и некорректный ввод отклоняются.

Отсутствующий ручной ввод означает dry-run. Обычный CLI также по умолчанию
работает без записи; изменение доски требует --apply. Автоматизацию включают
только после просмотра плана и приёмки ручного применения. Это устраняет окно,
в котором cron мог записать изменения раньше первого проверенного dry-run.

Слияние кода не создаёт токен, не включает переменные организации и не служит
проверкой реальной записи. Логика режимов проверяется с заглушками GitHub.
