# 0008. Колокольчик уведомлений и кабинет деканата

Дата: 2026-11-10. Статус: принято, реализовано (задача #10). Автор задачи: Legpopov.
Код и документ писал Claude Code, постановка и проверка — человек (интервью по скиллу grillme).

## Контекст

Ядро кабинета требовало раздел «Уведомления». Были только пуши Telegram-бота о справках и
переносах. Нужно окно в правом верхнем углу, где разворачиваются сообщения деканата,
преподавателей и вуза. Сотрудник деканата должен иметь возможность сам писать объявления.

## Решения

| Вопрос | Решение |
|--------|---------|
| Источники | Три метки: **Деканат**, **Преподаватель**, **Вуз** (цвет границы у каждой своё) |
| Откуда данные | Авто: статусы справок (`certificate_request_events`) и новые баллы/ДЗ (`grade_events`) читаются из существующих журналов при открытии ленты, ничего не копируется. Вручную: таблица `announcements` |
| Кто пишет | Сотрудник деканата — от имени деканата или вуза, всем / факультету / группе (кабинет `/d/announcements`). Преподаватель — только группам, у которых ведёт курс (`/t/announcements`). Чужая группа → ошибка, не рассылка |
| Почему свой кабинет деканата, а не Pyrus | Pyrus хранит согласование заявок, а не рассылку студентам: объявление нужно привязать к аудитории и показать в ЛК. Заявки на справки остаются в Pyrus ([0003](0003-dean-office-pyrus.md)) |
| Прочитано | Таблица `notification_reads (user_id, key)`. Развернул уведомление — прочитано; есть «Прочитать всё». Бейдж на колокольчике считает непрочитанное |
| Доступ | Лента строится по студенту/преподавателю из сессии, чужие события не видны (тесты). POST-роуты требуют CSRF |
| Telegram | Объявления в бот не дублируются (отдельное решение, если понадобится) |
| Сотрудник деканата | Колокольчика нет, это автор. Главная `/` ведёт на форму объявлений |

## Не сделано

- Переносы занятий (`lesson_changes`) в колокольчике: их по-прежнему присылает только бот.
- Редактирование и удаление объявлений, вложения, push за пределами ЛК.
- Преподаватель видит общие объявления деканата/вуза; адресные — только студентам.
