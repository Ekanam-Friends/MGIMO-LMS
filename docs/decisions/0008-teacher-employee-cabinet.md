# 0008. Кабинет преподавателя = сотрудник + преподавательские разделы

Дата: 2026-11-10. Статус: принято, реализовано. Дополняет [0007](0007-grades.md).
Автор задачи: Legpopov. Код и документ писал Claude Code.

## Контекст

В ЛК РАНХиГС (my.ranepa.ru/lk/employee) у любого сотрудника одна и та же структура, а
преподаватель — это сотрудник плюс группа меню «Преподавателю». Наш кабинет преподавателя
был коротким набором из четырёх пунктов. Структуру страницы «Сотрудник» снял Claude Code в
Chrome пользователя (без персональных данных: только названия разделов и блоков).

## Структура «Сотрудник» в РАНХиГС

- Меню: Главная; Сервисы Академии (список ссылок на системы); Научному сотруднику (Автору,
  Антиплагиат, Аттестация, Личная карточка, Учёному); **Преподавателю** (Конкурс ППС,
  Расписание, Учебная нагрузка); Кадровые сервисы (Заказ справок, Кадровые сервисы).
- Главная: информационная лента, плитки «Ресурсы Академии» (1С, Pyrus, Directum, адресная
  книга, база ЛНА, афиша, кадровый сервис, справочник нового работника, КЭДО, структура,
  навигация по кампусу), «Мои сервисы», блок «Кадровая служба», оплата парковки,
  бронирование помещений.
- Профиль: контакты, «Информация о сотруднике» (должность, подразделение, статус занятости,
  график, табельный номер), руководитель, история изменений.

## Решения

| Вопрос | Решение |
|--------|---------|
| Общая часть «сотрудник» | Главная `/t/home` (сегодняшние занятия, сроки ДЗ, плитки «Ресурсы Академии»), «Сервисы Академии» `/t/services`, «Кадровые сервисы» (каркасы), профиль с блоком «Информация о сотруднике» |
| Только преподаватель | Группа «Преподавателю»: Мои курсы, Домашние задания, Расписание (рабочие), Учебная нагрузка и Конкурс ППС (каркасы) |
| Не берём | «Научному сотруднику», парковка, бронирование помещений, лента новостей (ленту заменят «Объявления» из ветки уведомлений), настоящие ссылки на 1С/Pyrus/Directum |
| Кадровые данные | Должность, кафедра, табельный номер, ставка — детерминированные вымышленные значения от id преподавателя (`staff_card` в `teacher_views.py`). Миграция не нужна; при реальных данных поле придёт из кадровой системы |
| Каркасы | Через тот же `/s/<slug>`: `TEACHER_STUBS` вливаются в `STUBS` в `nav.py`, роут `views.stub` не менялся |
| Вход преподавателя | Теперь `/t/home` (раньше `/t/courses`) |
| Нижняя панель | 4 пункта (Главная, Курсы, Расписание, Профиль): пять не помещаются на 360 px |
