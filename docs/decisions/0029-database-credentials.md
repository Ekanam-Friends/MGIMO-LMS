# 0029. Доступ к демонстрационным аккаунтам через БД

Дата: 22 ноября 2026. Статус: принято.

Вход в LMS использует только запись `users` и проверку Argon2-хэша в
`app.auth.service.authenticate`. Открытые пароли и таблицы реквизитов удалены
из README и инструкции для жюри. Доступ команда передаёт отдельно.

Существующие логины и пароли сохраняются. Повторный запуск `app.seed` обновляет
демопрофили и связи преподавателей, но не пароли уже созданных пользователей.
`DEMO_PASSWORD` из непубликуемого окружения нужен для создания новых аккаунтов;
он не является запасным способом входа. Явная команда генератора
`app.generate.scale --apply --demo-access` по-прежнему может задавать пароль
принадлежащим генератору аккаунтам: это отдельная операция записи, не вход.

Миграция хэшей не нужна, если проверка БД подтверждает корректные Argon2-хэши.
Учётными записями внешнего Pyrus управляет Pyrus; его пароль не переносится в LMS.

По решению автора история Git не переписывается. Ранее опубликованные пароли
остаются известными из истории; удаление текущих публикаций не делает их секретными.
