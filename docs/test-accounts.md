# Тестовые учётные записи для жюри

Все данные вымышленные. Демо: **https://lms-university.ekanamfriends.ru**.
Логины и пароли для LMS и Pyrus команда передаёт отдельно; в репозитории их нет.

| Роль | Что посмотреть |
|------|----------------|
| Первый демонстрационный студент | «Успеваемость»: сильная зачётка без долгов, текущий накоп, ДЗ |
| Второй демонстрационный студент | «Успеваемость»: средний балл ниже, один академический долг |
| Преподаватель первой группы | «Мои курсы» → курс → балл в журнале или новое ДЗ; затем войти студентом группы и увидеть изменения |
| Преподаватель второй группы | То же для второго студента |
| Сотрудник деканата | Объявления в LMS; согласование заявок на справки — в Pyrus |

Проверка разделения данных: под `teacher1` откройте адрес курса `teacher2` (`/t/courses/<id>`)
— ответ 404. Под студентом любой адрес `/t/...` — 404.

Остальные ~3000 студентов созданы генератором (`python -m app.generate`, решение
[0007](decisions/0007-grades.md)): у них случайные пароли, которые нигде не сохранены, — войти
в эти учётки нельзя, они нужны для объёма данных в ведомостях.
