## Редактирование

Исходник всех четырёх схем — [scripts/render_diagrams.mjs](../../scripts/render_diagrams.mjs).
Для пересборки нужен только Node.js:

```bash
node scripts/render_diagrams.mjs
```

Команда обновляет четыре SVG в этой папке. Зависимости и сетевые запросы не нужны.
Исходник и результат следует менять в одном коммите. После изменения нужно открыть
все затронутые SVG и проверить подписи, направления стрелок и отсутствие наложений.

В файлах нет скриптов, внешних шрифтов и картинок. Русские подписи остаются текстом,
добавлены `title`, `desc` и альтернативные описания в местах включения. Палитра
единая: синий — сервисы, зелёный — данные и результат. Пунктир подписан по смыслу:
фоновая сверка Pyrus, поток WAL или выход бота через proxy. Статус реализации
не следует определять только по цвету или типу линии.

Схемы актуализированы по коду после PR #37–#41. Они не подтверждают новую
выкладку на VPS, полноту OCR, качество всех ответов или приёмку исторических норм.
