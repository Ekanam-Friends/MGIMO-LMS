# Ошибки ИИ и как их исправляли

| Дата | Задача | Что ИИ сделал не так | Как заметили | Как исправили |
|------|--------|----------------------|--------------|---------------|
| 2026-11-05 | Импорт расписания | Новое занятие вставлялось в БД до заполнения `last_seen_at` (NOT NULL) — каждый импорт падал | Первый прогон тестов: 9 из 19 упали с IntegrityError | Поля заполняются при создании строки |
| 2026-11-05 | Импорт расписания | При сбое группы посередине откатывалась транзакция, но не состояние в памяти: кэш id преподавателей, список новых занятий, счётчики изменений | Самопроверка кода до тестов | Преподаватели создаются отдельной транзакцией до группы; состояние группы откатывается вместе с ней |
| 2026-11-05 | Импорт расписания | Генератор выдал вымышленную фамилию, совпавшую с фамилией реального преподавателя МГИМО (риск «реальное ФИО» по правилам задания) | Аудит БД после живого импорта: сверка с сырыми ответами РУЗ | Стоп-лист фамилий из `/api/dictionary/lecturers` (только в памяти), переименование уже выданных имён, тест |
| 2026-11-05 | Импорт расписания | Alembic не находил пакет `app` (нет `prepend_sys_path`) | Ошибка при первой генерации миграции | `prepend_sys_path = .` в alembic.ini |
| 2026-11-05 | Импорт расписания | «Добавлено» определялось по покрытию дат прошлыми импортами, а не по группам: после пробного импорта 5 групп полный импорт записал бы в журнал все занятия остальных 1529 групп как новые | ИИ заметил, разбирая логику при переходе на параллельную загрузку; полный импорт остановлен до записи журнала | «Добавлено» только если группа занятия уже загружалась раньше; регрессионный тест |
| 2026-11-05 | Импорт расписания | При коммите в индекс попал `local.db-journal` (служебный файл SQLite от идущего импорта) | Проверка индекса перед коммитом | Убран из индекса до коммита, `*.db-journal`, `*.db-wal`, `*.db-shm` в .gitignore |
| 2026-11-05 | Импорт расписания | Пауза 1 с была выбрана «на глаз» и на деле почти ничего не значила (ответ сервера дольше паузы) | Пользователь предложил замерить лимит | Замер на 1/2/4 потоках, выбрано 2 потока |
| 2026-11-05 | Справки через Pyrus | Тест вебхука проверял только HTTP-коды, а не результат фоновой обработки — прошёл бы и при сломанной обработке | Самопроверка тестов после первого зелёного прогона | Тест переписан на `httpx.ASGITransport` в том же event loop, добавлена проверка статуса «Готова» и приложенного PDF |
| 2026-11-05 | Сайт кабинета | Роут входа брал флаги cookie (`Secure`, срок сессии) из `get_settings()`, то есть из `.env`, а не из настроек, переданных в `create_app` — тесты и прод могли получить разные флаги | Самопроверка кода после первого зелёного прогона тестов | Настройки кладутся в `app.state.settings` при старте и читаются оттуда |
| 2026-11-05 | Сайт кабинета | В первом черновике шаблонов были ссылки на несуществующие переменные (`kinds_title`, `timedelta7`) и запутанное условие раскрытия меню | Перечитывание шаблонов до запуска | Даты недели и список видов справок передаются из Python, условие меню переписано через `namespace` |
| 2026-11-05 | Выкладка демо | Дописал блок в Caddyfile общего Caddy и сделал `caddy reload`, считая, что файл в контейнере тот же. Контейнер монтировал старую версию файла (на хосте его когда-то заменили целиком), reload ответил «config is unchanged», сайт не открывался | curl к новому домену: TLS-ошибка; в логах Caddy — «config is unchanged»; сравнение `tail` файла в контейнере и на хосте | Пересоздан только контейнер caddy (`up -d --no-deps caddy`), подводный камень записан в docs/deploy.md |
