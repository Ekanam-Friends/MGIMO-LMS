доступного на запись каталога корпуса, см. `docs/staff-document-upload.md`.

## Исправления по ходу работы

Неуспешную загрузку разрешено исправить новым PDF по той же ссылке. Повторная
проверка публичности фиксируется временем загрузки, а повтор очереди не обновляет
это время. Захват задания и выбор исправляемого источника блокируют строку БД
в PostgreSQL; web всё равно рассчитан на один процесс, публикация CLI параллельно
с ним не поддерживается.

Тест общего лимита сначала посылал длинное поле формы. Парсер правомерно отклонял
его раньше лимита файла со статусом 400. Тест исправлен на потоковый multipart-файл:
проверяется именно ограничение загрузки и статус 413.
